HOW TO INSTALL

  1. Tap Download for Android. If your phone warns that this type of file can be harmful, choose Download anyway.
  2. Open the downloaded file. If asked, allow your browser to install unknown apps — that's a one-time switch in Settings.
  3. Tap Install, then open Salamin. Allow notifications when it asks, so your reminders can reach you.
